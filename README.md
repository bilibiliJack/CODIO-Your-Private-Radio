# CODIO

**陌生的歌曲，熟悉的听感。**

CODIO 是一款面向 Windows 的私人电台播放器，把音乐推荐、听歌记忆、AI DJ 和封面粒子放在同一个安静的桌面空间里。目前是持续打磨中的预览版，欢迎体验和反馈。

## 下载与开始

进入本仓库的 **Releases** 页面，下载最新的 Windows x64 ZIP 包。

1. 将压缩包完整解压到一个普通文件夹，不要直接在压缩包里运行。
2. 双击 `CODIO.exe`。
3. 通过应用内的 QQ 音乐官方登录窗口连接自己的账号；歌曲可用性取决于平台、地区及账号权限。
4. AI DJ 可选：在应用内连接自己的 DeepSeek API Key。调用费用由 DeepSeek 按你的账号计费；不使用 AI DJ 也能使用其他已连接的音乐功能。

支持 Windows 10 / 11 x64。建议联网使用。程序目前未做商业代码签名；请只从本仓库的正式发布下载，并核对发布附带的 SHA-256，不要随意关闭系统安全保护。

## 它在做什么

- **Right where you are**：围绕已证实的偏好寻找更贴合的歌曲，新歌也可以有熟悉的听感。
- **A little further**：沿着已有口味，有依据地探索稍远的方向。
- **听歌记忆与画像**：记录明确反馈与有效收听，区分长期偏好和临时听歌意图。单曲不喜欢不会直接封禁整个歌手。
- **AI DJ**：使用你自己的 `deepseek-v4-flash` 连接聊天、查询和本地工具；不会附送开发者的 Key 或额度。
- **Now Playing**：封面粒子、大小字/分栏歌词布局、音量波形、播放队列及播放控制。
- **逐句歌词**：支持普通 LRC，以及部分只提供 QRC 的 QQ 歌曲版本。平台未提供的数据不会伪装成真实歌词。

推荐、音源及第三方连接仍在改进中。歌曲级声音证据不足时会降低判断确定性，不承诺已理解每一首歌的音色或情绪。

## 隐私与边界

- 下载包不包含开发者的 QQ 登录、DeepSeek Key、画像、收藏、历史、曝光记录或音频缓存。
- 你需要使用自己的服务账号。DeepSeek Key 通过系统安全存储保存在设备上，不随发布包分发。
- 使用 AI DJ 时，聊天内容和必要的播放器/听歌状态会发给你选择并连接的 DeepSeek 服务。不愿发送这些信息时，请不要连接 AI DJ。
- CODIO 不提供音乐文件、不转售音乐会员、不绕过版权或会员权限。
- 此仓库只发布介绍、下载包和反馈信息，完整开发源码暂不公开。桌面程序包包含运行所必需的编译资源；这不等于前端代码具备绝对不可提取性。
